# 🎵 Thư mục Âm thanh & Nhạc nền (co-caro sounds)

Game đã tích hợp sẵn bộ phát âm thanh tổng hợp **Web Audio API** ngọt ngào, dễ thương chạy trực tiếp trên mọi trình duyệt mà không cần tải thêm bất kỳ file âm thanh nào.

Tuy nhiên, nếu bạn muốn sử dụng các file nhạc thật tùy chỉnh theo sở thích, hãy đặt các file MP3 vào thư mục này với tên tương ứng:

- `bgm.mp3`: Nhạc nền nhẹ nhàng, dễ thương lặp đi lặp lại.
- `click.mp3`: Âm thanh khi click đặt quân cờ.
- `win.mp3`: Âm thanh chiến thắng rộn ràng.
- `lose.mp3`: Âm thanh khi thua cuộc.
- `draw.mp3`: Âm thanh khi ván đấu hòa.

Game sẽ tự động ưu tiên phát file MP3 nếu có, và tự động dự phòng phát âm thanh Web Audio API nếu không tìm thấy file!
